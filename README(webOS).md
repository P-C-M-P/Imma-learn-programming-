# Frieren OS
This is a web OS mainly themed around frieren the anime: Frieren beyond journey's end

Currently it has four functioning windows, three of which are apps and one is a guide.
The video window currently only displays one video i found from pixabay(i don't remember the name, sorry).

The windows include as mentioned earlier four windows.

The first is a guide(about myself window), a notes app, a Grimoire collection(a work in progress), and the video window mentioned earlier.

# THE CODE
A large chunk of the js was the code provided in the guide, in particular the code that makes the window draggable and I kept the comments from there are well because the naming convention used in the code can be a bit confusing. There are also some bits of the code that I've commented out because i couldn't fix it but plan on implementing.

# AI usage 
Not much AI was used in the programs mainly because the guide is enough but i did try to use AI for the styling and a few ideas for apps, but none of those ideas have been implemented in this version.
